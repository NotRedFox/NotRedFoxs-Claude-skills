The saved example run breaks this rule: idea 4's first test is "One week", idea 5's is "Two weeks", idea 8's cost is "days". The docs describe the intended rule, so the README was left as is. The skill run, or the rule, needs a look.
- No code bugs were found in the example code. All runnable examples reproduced their recorded output. B6 in `kick-start/examples/invoice/BUGS.md` is a known open bug and is documented as such.
- Doc gap, not a false claim: `problem-solve/examples/washing-machine/problem-solve/tests/*.py` need numpy and scipy, which nothing in the README or the log says. Without them the scripts stop with `ModuleNotFoundError`.
