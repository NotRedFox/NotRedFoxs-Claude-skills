## Possible code bugs
Places where the docs look right and the code looks wrong.

- C8, README.md:26, `ignore_case=False`. The option exists and case folding is the default, but with `ignore_case=False` capital letters are dropped instead of kept, because the regex `[a-z']+` (`core.py:4`) only matches lower case. `count_words("The the", ignore_case=False)` gives `Counter({'he': 1, 'the': 1})`, so "The" turns into "he". A fix would be a case-aware pattern such as `[A-Za-z']+`. The test `test_case_kept` (`tests/test_core.py:14`) asserts `["A"] == 0`, so it passes with this behaviour and does not catch it. The README line was left as is.
